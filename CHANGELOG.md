# Changelog

## v0.1.0 — 2026-10-25

Initial release.

- Independent registries with a shared configuration loader.
- Per-kind registration and automatic loading of saved configurations.
- Explicit instance creation from JSON and in-memory lookups.
- Instance replacement, deletion, and optional persistence commits.
- Concurrent readers and coordinated mutations per key.
- Context cancellation, typed access, and instance listings.
